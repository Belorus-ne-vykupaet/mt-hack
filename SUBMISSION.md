## 4. Производительность и реализованные дополнительные возможности

Transit Hub — единое рабочее место диспетчера с прогнозами задержки к остановке в горизонте 10–15 минут, картой транспорта, центром событий и аналитикой первого прогноза и наблюдённого прибытия. Реализованы Яндекс Погода с анимированными облаками и дождём; адаптер Яндекс Router и дорожных событий с демонстрацией критического ДТП; рекомендации диспетчеру и текстовые отчёты GigaChat; модель Оли с 14 дополнительными историческими OSM-признаками; непрерывный ползунок движения автобусов 0–15 минут; устанавливаемое приложение для ПК и Android APK; интерактивная 3D-карта с моделями автобусов.

В минутном нагрузочном Docker-прогоне система обработала поток от 100 тестовых автобусов при 25 постоянных WS-клиентах: 1550 HTTP-запросов без ошибок, 44 950 доставленных WS-сообщений, 0 неожиданных разрывов, P95 HTTP 550,25 мс. Восстановление API после принудительного сбоя заняло 7,10 с. Пройдены 155 тестов приложения/API, 149 Python-тестов и полный набор из 15 браузерных сценариев; также прошли проверка типов, lint и production-сборка.
