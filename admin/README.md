# Добавление маршрутов администратором

Это инструмент для человека с доступом к исходному коду и правом публикации проекта. На сайте нет редактора, скрытой административной страницы или открытого API записи. Не раздавайте доступ к репозиторию обычным пользователям. В production публикуется только `dist/`; граф `admin/data/` и скрипты в сборку не входят.

## Добавить маршрут по остановкам

Из корня проекта:

```sh
pnpm routes:stops --search Будённого
pnpm routes:stops
pnpm routes:add --number ДемоМ3 --stops 10707555437,10702781016,1383980899 --dry-run
pnpm routes:add --number ДемоМ3 --stops 10707555437,10702781016,1383980899
pnpm routes:validate
pnpm build
```

В `--stops` передавайте ID из списка в порядке движения. Имя автоматически составляется из конечных остановок; своё можно передать через `--name "Название маршрута"`. Одноимённые платформы имеют разные ID. Между остановками строится кратчайший связный путь **только по импортированным дорогам автобусных маршрутов и в импортированном направлении**. Укажите промежуточные остановки для нужной трассы. В список остановок нового маршрута попадают только выбранные остановки. Петли, повторы и несвязные участки отклоняются; прямые линии между несвязанными остановками не рисуются.

`--dry-run` проверяет результат без изменения файлов. Существующий номер не перезаписывается без явного `--replace`. Для параллельных записей используется блокировка. После сбоя процесса удаляйте `admin/data/.routes-lock` только убедившись, что другой импорт не запущен.

Граф сейчас покрывает направления 15 включённых маршрутов. Для других направлений сначала импортируйте связное отношение OSM:

```sh
pnpm routes:import --relation 3132036 --replace --dry-run
pnpm routes:import --relation 3132036 --replace
```

Нужен ID именно отношения `route=bus`, не route_master. Импорт использует публичный OSM API, проверяет порядок путей и остановок и не соединяет разрывы вымышленными отрезками. Новые пути и остановки расширяют доступный граф. Обратное направление импортируется отдельно. Отношение с разрывами нужно исправить в исходных данных или выбрать другое.

## Применить изменения

Проверьте изменения `src/data/moscow-buses.json` и `admin/data/bus-network.json`, выполните `pnpm routes:validate && pnpm check`. В `pnpm dev` каталог обновится автоматически. Для preview заново соберите `pnpm build`, запустите `pnpm preview --host 127.0.0.1 --port 4173` и обновите браузер. Публикуйте только `dist/` через принятый в команде процесс.

По умолчанию для нового маршрута создаются 8 демонстрационных автобусов. Это не подключение к реальной телеметрии. При `VITE_USE_MOCKS=false` маршруты и геометрия приходят от внешнего backend: этому backend нужно отдельно передать подготовленный каталог.
