# Улучшение модели относительно sasha

На исходном `labels_test` (353 строки) MAE уменьшена с **58,09 до 27,42 секунды**.
После исключения синтетических копий целевых остановок test/validate результат новой модели — **37,03 секунды**.
Это оценки локального подбора. Официальный скор на платформе ещё не измерен.

**Основной файл для отправки:** `outputs/submission_improved.csv`.
Он получен после дообучения зафиксированной конфигурации на доступных train + test.
Полная разметка validate не используется. Все сабмиты: UTF-8, `sample_id;prediction`, 151 строка.

## Что изменено

- Меньшее сглаживание: `min_samples_leaf=1` вместо 5.
- Добавлен контекст опубликованного расписания: положение остановки, интервалы, длина пути, перерывы между рейсами.
- Дополнительные признаки движения: стоянки, путь, перемещение, скорость и оценка положения на плановом маршруте.
- Вместо среднего используется медиана прогнозов деревьев, которая лучше соответствует MAE.
- Две группы признаков (`ctx` и `all`), по три seed (2026, 17, 43), по 400 деревьев.
- Внутри группы — медиана всех 1 200 деревьев; итог — равные веса двух групп.

Более сложная нейросеть здесь не оказалась необходимой: лучший результат дала доработанная модель ExtraTrees.
Исходная GRU и её API сохранены. Новый пакетный предиктор находится в `src/mt_hack/improved.py`.

## Проверка результата

| Проверка | Исходный ExtraTrees sasha | Улучшенная модель |
|---|---:|---:|
| Исходный test, полный train | 58,09 | **27,42** |
| Тот же test, без синтетических целей test/validate | 62,08 | **37,03** |
| Хронологическая проверка: обучение до 15:30, оценка с 20:00 | **57,80** | 59,86 |

Для проверки без пересечений исключены 295 из 4 434 строк. Источник синтетической копии определяется
по геометрии и порядку плановых остановок, без чтения их фактических задержек.
Исходный очищенный ExtraTrees проверялся с 240 деревьями; новый — ансамбль из шести моделей.
Хронологический стресс-тест нового варианта использует по одной модели на группу, seed 2026;
он не использовался при выборе гиперпараметров. Его результат не улучшился.
Низкая MAE на случайном разбиении одного дня не доказывает качество на новом дне.

`sasha` и `olya` указывали на один коммит `fc4e87b`. В `main` (`1bf9f8a`) сохранён CatBoost с MAE 62,69.
Baseline sasha в текущем окружении воспроизведён с MAE 58,10; незначительное отличие от 58,09
и различия отдельных предсказаний зафиксированы в отчёте, версии окружений различаются.

Подробные метрики: `reports/improvement_metrics.json`, `reports/IMPROVEMENT.md`.

## Прогноз из готовых весов

```powershell
python -m pip install -r requirements-improved.txt
python scripts/predict_improved.py --data ../data --model artifacts/improved_final --output outputs/submission_reproduced.csv
python scripts/verify_improved.py
```

`--data` — распакованный датасет с папками `train`, `test`, `validate`, `labels` и шаблоном сабмита.
В текущем рабочем окружении зависимости дополнительно доступны в `../.deps`.
Модель не читает кеш экспериментов при инференсе; достаточно исходных CSV и `artifacts/improved_final`.
Файлы joblib следует загружать только из доверенного источника.

## Воспроизвести эксперименты

Команды запускаются из корня репозитория; скрипты исследования ожидают датасет в `../data`.

```powershell
python scripts/research.py
python scripts/tune_improved.py --prepare-only
python scripts/tune_improved.py --stage screen
python scripts/tune_improved.py --stage fast
python scripts/aggregate_search.py
python scripts/audit_improved.py
python scripts/finalize_improved.py
python scripts/report_improvement.py
```

Для всех исходных и новых тестов установить зависимости проекта с dev-группой (`python -m pip install -e ".[dev]"`), затем:

```powershell
python -m pytest -q -p no:cacheprovider
```

Результаты отдельных запусков кешируются в `work/improvement`. Для новых параметров/изменённой логики
используйте новые имена экспериментов или отдельный рабочий каталог: кеш автоматически не инвалидируется.

## Артефакты

- `artifacts/improved_final`: итоговые веса после обучения на train + test, 4 787 строк.
- `artifacts/improved_full`: веса, которыми измерен результат 27,42 на test; обучение только на train.
- `artifacts/improved_purged`: веса проверки без синтетических пересечений.
- `outputs/submission_improved.csv`: основной сабмит после дообучения.
- `outputs/submission_full_train_only.csv`: прогноз варианта, обученного только на train.
- `outputs/submission_purged_train_only.csv`: консервативный вариант без синтетических целей test/validate.
- `reports/improved_full_test.csv`, `reports/improved_purged_test.csv`: все локальные предсказания.

Большие веса, входные данные и рабочие кеши исключены из Git; код и отчёты сохранены в отдельной ветке.
Прогноз использует только телеметрию `event_time <= T`, `cur_dev_s` текущей точки и план.
`time_fact_begin` и целевые значения никогда не включаются в признаки.
