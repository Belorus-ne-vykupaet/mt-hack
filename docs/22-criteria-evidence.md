# Transit Hub — проверка по критериям

Каждое требование связано с реализацией, воспроизводимым действием и сохранённым результатом. Основной проверенный код — `12b946f`; [инструкция для жюри](../JURY_QUICKSTART.md) проводит через запуск и демонстрацию, [техническая документация](../DOCUMENTATION.md) раскрывает устройство системы.

## Автоматические проверки текущего кода

**306 успешно пройденных проверок:** 155 тестов приложения/API, 146 Python-тестов, 5 браузерных сценариев. Проверки типов, lint и production-сборка также прошли. Результаты связаны с кодом, окружением и командами повторения в [протоколе](28-karatai-reliability-review.md).
