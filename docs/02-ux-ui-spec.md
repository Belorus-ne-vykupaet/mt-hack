# Transit Control — UX/UI v2

Основное арт-направление и референсы: [Visual direction v2](00-design-direction-v2.md).

## Два контекста

### Вход `/`

Один полноэкранный авторский 3D-вход. Крупная типографика, светлая сцена, скульптура движения. Главное действие «Открыть диспетчерскую». Нет искусственной загрузки, обязательного звука или блокировки входа. Логотип из рабочего пространства возвращает на заставку.

### Рабочая среда

`/overview` — карта и ситуация сейчас; `/analytics` — показатели и динамика; `/flow` — пространственное развитие потоков. Прямые ссылки открываются без заставки.

## Композиция

Светлая нейтральная основа, графитовые буквы и тонкие разделители. Лаймовое главное действие. Компактная навигация вместо тяжёлой панели управления. Большой заголовок задаёт ритм; одно основное полотно карты и одна контекстная панель. Краткая сводка встроена над картой, подробные диаграммы находятся в аналитике. Избегать отдельных рамок вокруг каждого числа.

Минимум декоративного интерфейса: убрать повторяющиеся подписи, технические слоганы, лишние бейджи, дубли KPI и названия города в каждом блоке. Показывать только информацию, полезную диспетчеру.

## Взаимодействия

Выбор события → маршрут → ТС сохраняется. Выделение маршрута, карта и контекстная карточка связаны одним состоянием. Поиск находит маршрут, ТС, остановку. Фильтры маршрута и риска сохраняются между режимами. Timeline: сейчас / +3 / +6 / +10 / +15. Прогноз отличается от факта пунктиром и явной подписью.

## Доступность и движение

Все действия доступны с клавиатуры, кнопки имеют названия и видимый фокус. Hover дополняет click/tap. Предпочтение reduced motion останавливает автоматическое вращение и сокращает переходы. Заставку можно пропустить немедленно. Контент и кнопка входа видны при ошибке WebGL. Уменьшенный экран получает один столбец и прокрутку вместо обрезанных боковых панелей.

## Состояния данных

Loading — локальная заглушка, не fullscreen 3D loader. При offline/stale последняя сводка остаётся; видны статус и время последнего обновления. Ошибка карты изолирована от данных и навигации. Empty state и исчезнувший выбранный объект объясняются коротким текстом.

## Основной demo-flow

Заставка → Открыть диспетчерскую → Обзор → критическое событие маршрута 37 → карточка → транспорт → +15 минут → Потоки. Также проверять прямой вход `/overview`.
